# 프로젝트 개요

## 프로젝트명

SSL VPN 인증서 및 운영 자동화 플랫폼

## 배경

고객사 VPN 인증서 발급과 재등록, 장비별 연결 정보 관리, 레거시 장비 대응, 백업 점검, 장애 모니터링이 수작업 중심으로 운영되고 있었습니다.

인증서 운영 업무가 사람의 기억과 절차에 많이 의존하다 보니 아래 문제가 반복적으로 발생했습니다.

- 인증서 발급/재발급 처리 지연
- 장비 유형별 정책 차이로 인한 운영 혼선
- 라우팅 / NAT / 방화벽 누락으로 인한 통신 장애
- 백업 및 서비스 상태에 대한 실시간 가시성 부족
- 운영 서버와 개발 환경 간 기준선 불일치

## 목표

- 인증서 발급부터 운영 상태 확인까지 웹 기반으로 통합
- 일반 SG, Legacy SG, SFOS 장비를 유형별로 안정적으로 운영
- 백업, 모니터링, 알림, 장애 대응 절차를 시스템화
- 운영 서버와 개발/검증 환경의 일관성 확보

## 내가 맡은 역할

- FastAPI 기반 백엔드 구현
- React 기반 운영 UI 개발
- OpenVPN / CCD / IP 임대 로직 정리
- 설치 스크립트 및 운영 자동화 스크립트 개선
- 보안 모니터 및 슬랙 알림 흐름 설계
- 운영 반영본과 로컬/검증 환경 동기화

## 기대 효과

- 수작업 중심 운영 절차 감소
- 장애 원인 추적 속도 향상
- 운영 정책 표준화
- 유지보수 기준선 명확화
