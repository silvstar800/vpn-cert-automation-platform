# 주요 기능 정리

## 1. VPN 인증서 발급 및 재등록

- OpenVPN 기반 인증서 발급 자동화
- 재등록 시 기존 운영 흐름을 최대한 유지
- 일반/레거시 장비별 유형 구분 적용

## 2. APC 요청 생성

- 장비 기반 APC 생성 요청 처리
- 운영 포털에서 요청 이력 관리
- 장비 정보와 연계 가능한 구조 마련

## 3. IP 임대 및 CCD 관리

- 클라이언트별 IP 임대 현황 관리
- CCD 기반 라우팅 및 장비별 네트워크 설정 분리
- 일반 SG / Legacy SG / SFOS 대역 구분 운영

## 4. 장비 / 라이선스 관리

- 시리얼 기반 장비 관리
- 장비 모델, 라이선스, 상태 추적
- 외부 연동 기반 고객사 정보 연결 구조

## 5. 인증서 만료 추적

- 인증서 상태 시각화
- 만료 예정 / 만료 / 여유 상태 구분
- 운영자 확인 대상 빠른 식별

## 6. 보안 모니터

- 관리자 비밀번호 기반 진입 제어
- 슬랙 알림 설정
- 서비스 다운 / 백업 완료 / 침입 시도 감지 이벤트 관리

## 7. 백업 / 복구 검증

- FTP/NAS 대상 백업 설정
- 복구 전 검증 모드 제공
- 백업 결과 및 검증 로그 기록

## 8. Runtime Guard

- 재부팅 후 서비스 상태 점검
- 인터페이스 및 방화벽 규칙 점검
- 스크립트 실행 기반 자동 복구 흐름 지원
