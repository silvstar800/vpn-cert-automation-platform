# 실제 코드 참고

이 폴더는 포트폴리오 설명에 사용한 실제 프로젝트의 핵심 소스를 참고용으로 정리한 공간입니다.

## 구성

- `backend`
  - FastAPI 기반 운영 API
  - 장비 / 인증서 / 백업 / 모니터링 관련 도메인 로직 포함

- `frontend`
  - React / Vite 기반 운영 포털 UI
  - 대시보드, 클라이언트 관리, 장비/라이선스, 보안 모니터 등 화면 포함

## 참고

- 실제 운영 저장소 전체를 옮긴 것이 아니라, 포트폴리오 설명에 필요한 핵심 프론트/백엔드 소스 중심으로 정리했습니다.
- 인프라 설정, 민감 정보, 배포 환경값은 제외하거나 분리된 상태로 관리합니다.
